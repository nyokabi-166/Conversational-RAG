# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a vulnerability or security issue:

1. **Do NOT open a public GitHub Issue.**
2. Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com) or by emailing the project maintainers directly.
3. Provide detailed steps to reproduce the issue, along with proof of concept if available.

### What to Expect

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide regular updates on progress toward resolving the issue.
- A fix will be developed and released through a security advisory release.
